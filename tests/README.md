# tests/

`expected_results.json` is produced by `python3 reference/run_case.py --write-expected` (M2) and is the contract
between the reference implementation and anything generated by an agent. Structure:

```json
{
  "generated_by": "reference/run_case.py", "snapshot": "<meta.json crawled_at>", "bundle_sha256": "<sha>",
  "tolerance_rel": 0.01,
  "systems": {
    "SVE": {
      "totals": {"Climate change": {"value": 0.0, "unit": "kg CO2 Equivalents"}, "...": {}},
      "by_stage": {"Climate change": {"operation": 0.0, "gac": 0.0, "...": 0.0}},
      "cutoffs": [{"item": "microorganism", "amount": 4777, "unit": "L"}],
      "n_processes_solved": 0
    },
    "Biopile": {}
  },
  "identities": ["sum_process_equals_total", "sum_stage_equals_total"]
}
```

Until M2 is done the file contains the structure with `null` values; tests must fail loudly rather than pass vacuously.
