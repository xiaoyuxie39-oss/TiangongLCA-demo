# web/

Generated by Codex CLI from `prompts/00_build_tool.md` in the 2026-10-02 rehearsal (12 min, no human edits) and committed as the fallback for the live build.
Since then it is the **student edition** (`prompts/03_student_edition.md`): names instead of uuids, a dataset card behind every
provider, a flow drill-down and a banner when the two systems use different background data. Files:

- `index.html` — UI wiring (vanilla JS, optional Chart.js from CDN); carries a gzip copy of the bundle for `file://`, refreshed by `reference/build_case_bundle.py`
- `lca_core.js` — pure functions: `buildSystem`, `solve`, `lcia`, `contributions`, `flowByProcess`, `unitImpacts`
- `lca_ui.js` — pure HTML builders for every panel and the dataset card (no DOM), so the test can render them in Node
- `test.mjs` — `node web/test.mjs` compares against `tests/expected_results.json` and checks the student view for uuid leaks
- `data/case_bundle.json` — generated by `reference/build_case_bundle.py`; do not edit by hand

Instructor view: open a local copy (`web/index.html` from disk, or `python3 -m http.server --directory web`) with `?audit=1`
to see uuids, resolution rules and data warnings. The public Pages site ignores the parameter, so students never see them.

Deployed to GitHub Pages by `.github/workflows/pages.yml` on every push to `main`. Run the live build in a separate clone and do
not push its `web/` over this one.
